Activate through Bluetooth.

Send WiFi credentials over BLE first, open the installer on your home network, then install production firmware whenever you are ready.

bluetooth desktop chrome or app 2.4 GHz WiFi install firmware later

Before you start

  • Have the name and password for your 2.4 GHz WiFi network ready.
  • For browser setup, use desktop Chrome on a Windows PC or Mac.
  • Phone browsers cannot complete this setup because they do not expose the required Web Bluetooth API.
  • For phone setup, use the official ESP BLE Provisioning app by Espressif instead.
  • Download the latest production kiri_bridge_... .kiri file before the OTA step.

1. Power the device

  1. Plug Kiri Bridge into USB power, or connect it to the Mitsubishi indoor unit's CN105 port.
  2. Wait about 10-20 seconds.
  3. Confirm the LED is blinking blue quickly. This means BLE provisioning is available.

If the LED does not blink blue

  • Unplug the device, wait 5 seconds, and plug it back in.
  • If setup mode still does not appear, follow the USB recovery guide.

2. Send WiFi from a browser

  1. Open BLE WiFi provisioning in desktop Chrome on a Windows PC or Mac.
  2. Click LED is blinking blue.
  3. Click Open BLE picker.
  4. Choose the nearby device named PROV_KIRI_....
  5. Enter your home WiFi SSID and password.
  6. Click Send credentials and wait for the success message.
Success looks like this: the page shows an IP address and an access portal link such as http://192.168.1.42:8080/.

Alternative: use the Espressif phone app

  1. Install the official ESP BLE Provisioning app by Espressif on iPhone or Android.
  2. Open the app and select Provision Device.
  3. Select I do not have a QR code.
  4. Choose the device named PROV_KIRI_....
  5. If prompted for a Proof of Possession (PoP), enter abcd1234.
  6. Select your 2.4 GHz WiFi network, enter its password, and follow the app instructions.
You only need one BLE method. Use either the browser tool or the Espressif app, not both.

3. Open the local installer portal

  1. Open the access portal link reported by the browser tool, or find the Kiri Bridge IP address in your router after using the phone app.
  2. Visit http://IP:8080/.
  3. Complete Step 1 device settings and click Save and Continue.
  4. Run the optional CN105 smoke test if the device is connected to the indoor unit, or skip it.

4. Install production firmware

  1. In the OTA upload step, click Choose Firmware.
  2. Select the latest kiri_bridge_... .kiri production package.
  3. Wait for upload and validation to finish.
  4. Review the confirmation dialog, then confirm the reboot.
  5. When the reboot dialog finishes, reopen http://IP:8080/.
Use the .kiri file, not a .bin file. The package metadata helps prevent accidental installation of the wrong firmware.

5. Pair with Apple Home

  1. Open the Kiri Bridge portal after production firmware boots.
  2. Use the displayed HomeKit pairing code.
  3. On iPhone, open the Home app, tap +, then Add Accessory.
  4. Scan the QR code or enter the pairing code manually.
