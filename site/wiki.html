Kiri Bridge wiki.

Short, practical guides for activating a new device, recovering a stuck device, or installing firmware over USB when OTA is not the right path.

01 Start Here

New device activation

For a Kiri Bridge kit that just arrived and already blinks blue after power-on.

Activate a new Kiri Bridge

Use Bluetooth once to put the device on WiFi, then finish setup from the local portal.

new kit bluetooth 2.4 GHz WiFi
  1. Power the Kiri Bridge and wait for a fast blue blink.
  2. Open WiFi setup in Chrome or Edge and send your 2.4 GHz WiFi credentials.
  3. Open the device portal at http://IP:8080/ once the setup page reports an IP address.
  4. Use OTA on the portal to install the latest production .kiri release.
  5. After reboot, open the portal again and pair the device in the Apple Home app.

02 Recovery

Fix a broken or stuck install

For OTA failures, unreachable web UI, bad configuration, or support-directed recovery.

Re-flash the installer over USB

The browser verifies the ESP32, checks the .kiri package, then writes the installer firmware over USB serial.

recovery usb serial chrome / edge
  1. Connect the Kiri Bridge to your computer over USB.
  2. Open the recovery flasher and select the serial device.
  3. Choose the installer .kiri package from GitHub Releases.
  4. Confirm the hardware summary and write the package.
  5. Restart the device manually, wait for the blue blink, then run WiFi setup again.

03 Advanced

Manual firmware install

For users who prefer USB flashing, or when support asks you to avoid OTA for a specific update.

Update firmware over USB instead of OTA

This is the same flasher as recovery, but used deliberately as a manual install path.

manual update support no OTA
  1. Download the instructed .kiri release before starting.
  2. Connect the Kiri Bridge to USB and open the recovery flasher.
  3. Select and verify the board, then choose the firmware package.
  4. Write the package and restart the device manually when the success dialog appears.
  5. If you installed the installer package, continue through BLE WiFi setup before installing production firmware.
